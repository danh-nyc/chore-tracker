# Goody!

## Video Demo: https://youtu.be/tl_ug95L2qs

A simple web application that helps families manage chores and rewards for kids. 

## Overview

1. This app has two roles: Parents & Kids
2. Parents can
    a. Register and create a new household or join an existing household
    b. Add one more more kids to their households
    c. Create chore templates with assigned point values
    d. Create prize templates with assigned point costs
    e. Review and approve / reject chore and prize requests from kids
    f. View dashboard with a summary view of items needing action
3. Kids can
    a. Login with a username and password
    b. Create chore submissions to send to parents for approvals
    c. Earn and view their points total
    d. Create prize requests to redeem their points

## Technology Stack

- **Backend:** Python / Flask  
- **Database:** SQLite  
- **Frontend:** HTML, Jinja Templates, Bootstrap  
- **Authentication:** Session-based login
